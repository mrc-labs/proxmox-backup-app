Privacy Policy

Mauro Proxmox Backup. Last updated: 29 October 2026.

Purpose and information accessed

This personal desktop utility uses Google Drive to store and retrieve the owner's encrypted backup files and to verify transfers. Its only requested Google API scope is https://www.googleapis.com/auth/drive.file. That scope permits creating, reading, updating and deleting files created by this app or explicitly made available to it. The utility does not request unrestricted access to other existing Drive files, Gmail, contacts or calendars.

Storage and security

The rclone client encrypts backup contents and filenames locally using Crypt before upload. Google stores the encrypted files in the authorized account and still processes operational metadata such as file sizes, timestamps and API requests. Encryption does not hide all metadata from Google.

OAuth client configuration and tokens are stored in the owner's private local client configuration. Encryption keys are separate local secrets. Local operational logs may include transfer metadata. Tokens, encryption keys and unencrypted backups are not published on this website or in its public source repository.

Use and sharing

Google user data is used only to perform the backup and recovery operations requested by the owner. It is not sold, used for advertising, shared with analytics providers or used to train AI models. The maintainer operates no separate server collecting the owner's Google user data. Google processes requests and stored files under its own terms and privacy policy. The application's use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

The owner controls retention and can delete uploaded files in Google Drive, subject to Drive's trash and retention behavior, and remove local copies and credentials. Revoking the app in Google Account settings prevents further authorized API access; it does not automatically delete previously uploaded files or local copies. Keep encryption recovery keys privately available for any backups that must remain recoverable.

This website and contact

These static pages set no application cookies and include no analytics, tracking scripts or login form. GitHub Pages hosts the site and logs visitors' IP addresses for security according to GitHub's documentation.

Maintainer: mrc-labs on GitHub. Use the support email on the Google consent screen for private privacy questions. Do not include secrets in public communications.
