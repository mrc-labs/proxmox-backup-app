Mauro Proxmox Backup

A personal utility for copying encrypted backup archives to the owner's Google Drive and retrieving them for recovery checks. It uses a locally operated rclone client; this website is informational and does not run backups or request Google sign-in.

Google Drive access

The desktop client requests only the drive.file permission, which allows it to create and manage files and folders created by this app or explicitly made available to it. It does not request unrestricted access to existing Drive files.

Backup contents and filenames are encrypted locally with rclone Crypt before upload. The owner controls authorization, encryption keys, backup selection and retention. No public backup-sharing service is provided.
